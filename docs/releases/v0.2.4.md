# RMA System 0.2.4

This release fixes a recovery gap during photo intake. If an image was saved but the recognition queue was temporarily unavailable, uploading the same image again now retries queueing instead of reporting success while leaving the display unprocessed.

## Get the images

```bash
docker pull ghcr.io/arslanbasharat-o-o/rma-system:0.2.4
docker pull ghcr.io/arslanbasharat-o-o/rma-system:worker-0.2.4
```

Both images are published together in the [public container package](https://github.com/arslanbasharat-o-o/RMA-System/pkgs/container/rma-system). The web app and background worker use the same release version. This project is available under the [MIT License](../../LICENSE).

For an existing installation, follow the [deployment guide](../../DEPLOYMENT.md) to back up data and update the app and worker images. A release does not deploy to your server automatically.

## Verification

The release workflow runs the full desktop and mobile browser suite, with recognition providers mocked. It validates and publishes both container images only after checks pass. No paid recognition request is part of release validation.
