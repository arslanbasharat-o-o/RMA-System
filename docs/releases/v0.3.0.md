# RMA System v0.3.0

This release removes the retired SerpApi provider and moves the separately
maintained Google Lens API and Scrapling Chrome worker to the
[Google Lens API repository](https://github.com/arslanbasharat-o-o/Google-Lens-API).
The RMA release publishes the web and queue-worker images; the API repository
publishes its own versioned packages.

Recognition now retains up to 20 ranked Google Lens matches. Apple display
variants require at least three independently attributable merchant domains and
a clear ranking margin before a model is suggested. Weak, mixed, accessory-only,
or unattributed matches remain unresolved for staff review. Catalog matching no
longer converts a weak visual decision into a specific device model.

The camera intake screen now shows recognition progress and completed results
while an operator continues capturing the next display.

No schema migration is required. Production customer, RMA, and image records
remain in their existing database and storage volumes.
