# RMA System v0.3.17

## Highlights

- **Candidate Suggestions Preserved**: When visual evidence exhibits variant competition (such as iPhone 15 Pro vs Pro Max), the top candidate is preserved as an actionable `[Suggestion]` with `review_required` status, instead of degrading into `Unidentified Display`. Operators can review and confirm suggestions directly from the table or inspection drawer.
- **Snapshot Round-trip & Policy v7**: `suggestedModel` is preserved through snapshot storage and retrieval, and the visual decision policy is bumped to v7 so prior inconclusive v6 machine caches are automatically superseded by the preserved candidate evidence.
- **Expanded Brand Coverage**: Recognition now extracts and identifies displays for Nokia (e.g. Nokia G10 / G20), Sony Xperia, LG, Realme, and Vivo.
- **Queue Worker Docker Healthcheck**: Added native process healthcheck to the worker service in `docker-compose.yml`, ensuring Uptime Kuma and deployment monitors accurately report worker process health.
- **End-to-End Test Suite Robustness**: Refined Playwright text matching across the full browser test suite.
