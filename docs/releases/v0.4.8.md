# Release v0.4.8 — Google Lens v1.0.22 Multisearch Integration

**Release Date:** 2026-10-29

## Overview
Release v0.4.8 integrates Google Lens API v1.0.22 multisearch inspection prompt support into the RMA System background worker and application services.

## Highlights
- **Compose Forwarding**: Configured `LENS_SEARCH_PROMPT=${LENS_SEARCH_PROMPT:-}` in `docker-compose.yml` for both `app` and `worker` containers, ensuring environment variables from `/opt/rma-system/.env` pass directly to container runtimes.
- **Provider Prompt Precedence**: Updated `SelfHostedLensProvider` (`src/lib/recognition/lens/self-hosted.ts`) and background queue processor (`src/lib/queue/processor.ts`) to prioritize configured inspection prompts (`process.env.LENS_SEARCH_PROMPT`) over defaults.
- **Admin Settings Display**: Added `lensSearchPrompt` to `providerStatus` in `/api/settings` and displayed the active inspection prompt under the Visual Recognition card in Settings.
- **Documentation & Configuration**: Updated `.env.example` and `docs/self-hosted-lens.md` with Google Lens v1.0.22 image references (`:1.0.22`) and multisearch prompt details.
- **Verification**: Verified with automated unit tests across `self-hosted-lens-provider.test.ts` (all 227 tests passing).
