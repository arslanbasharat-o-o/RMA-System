# RMA System 0.2.2

This release makes it easier to understand what RMA System does and how to get it running.

## What's included

- A shorter project introduction with direct links to releases, container images, local setup, and deployment instructions.
- Separate descriptions for the web app and background worker on the published container images.
- Versioned Docker image tags for both services.

## Get the images

```bash
docker pull ghcr.io/arslanbasharat-o-o/rma-system:0.2.2
docker pull ghcr.io/arslanbasharat-o-o/rma-system:worker-0.2.2
```

The [container package page](https://github.com/arslanbasharat-o-o/RMA-System/pkgs/container/rma-system) lists both services and their tags. The release uses the MIT license. Publishing it does not update an existing server; follow the [deployment guide](https://github.com/arslanbasharat-o-o/RMA-System/blob/main/DEPLOYMENT.md) for a controlled rollout.

## Verification

The release workflow runs the project checks, builds both container images, runs the desktop and mobile browser suite with mocked recognition providers, and publishes the release and images after validation passes.
