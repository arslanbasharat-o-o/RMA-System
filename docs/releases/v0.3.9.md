# RMA System 0.3.9

This release refreshes old recognition results when an image is processed under the current Lens evidence policy. Identical images reuse the current result, including an unresolved result, so the system avoids repeated Google Lens requests. When current results disagree, the model remains unidentified for operator review and the fresh overview and candidate listings remain visible.

## Verification

- Regression coverage exercises legacy conflicts, current-policy cache reuse, stronger fresh evidence, and candidate retention for conflicts.
- Local tests use the mock Lens provider. Live visual checks use the production Lens adapter and do not run OCR or paid AI requests.
