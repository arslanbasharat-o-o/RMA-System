# RMA System v0.2.9

This patch release fixes production startup readiness for the self-hosted Google Lens service.

- Adds a Redis healthcheck required by the API and Scrapling worker dependencies.
- Adds a CI smoke check that starts the production Compose Redis service and waits for healthy status.

The release also includes the v0.2.8 Scrapling integration and RMA provider changes. It does not require a database migration.
