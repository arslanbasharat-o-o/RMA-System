# Release v0.4.10 — Clean Operator Review Alerts & Modern Display Differentiation

**Release Date:** 2026-10-30

## Overview
Release v0.4.10 refactors the Review Queue "Reason For Review" alert presentation into clean, readable, professional guidance, strips internal rule engine debug logs from operator-facing evidence notes, and prevents false legacy iPhone 7 Plus suggestions on modern 19.5:9 displays with OLED markings.

## Highlights
- **Human-Readable Review Reasons**: Replaced raw pipe-delimited (` | `) debug log dumps in the Review Queue with clean, bulleted, elegant reason alerts.
- **Removed Debug Leakage**: Stripped internal matcher rule evaluation telemetry (`Evaluated X tokens against Y active rules with no match`) and stale internal catalog references from operator notes.
- **OLED Technology Ground-Truth Gate**: When physical markings confirm OLED technology (`HARD` or `SOFT` OLED), legacy LCD-only models (iPhone 6, 7, 8 series) are automatically eliminated from visual search candidate scoring.
- **Rear View & Proportions Inspection**: Enhanced the multimodal AI vision gate with explicit physical guidance on rear metal heat shield backing plates (standard on modern aftermarket displays), 19.5:9 all-screen aspect ratios, and aftermarket generation stickers (`AL16`).
