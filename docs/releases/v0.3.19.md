# RMA System v0.3.19

- Remove an incorrect intake photo using the visible × control on desktop and mobile, then add its replacement to the same display.
- Automatically show recognition results as processing finishes; mobile resume and reconnect no longer depend on clicking a refresh control or reloading the page.
- Keep captured photos and recognition results reachable on small phone screens.
- Invalidate stale results when a photo is removed. Remaining photos and their replacement recognition job commit together; verified displays and historical audit records remain protected.

This release uses the existing database schema. Application images must be deployed together with the existing persistent database and image volumes preserved.
