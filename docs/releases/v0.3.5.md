# RMA System v0.3.5

This release stabilizes display identification for repeated uploads of the same
photo. The worker records the image checksum and decision policy, reuses an
operator-confirmed or supported visual result for identical bytes, and sends
conflicting credible model evidence to review. Google Lens AI Overview is
optional supporting evidence alongside up to 30 attributable listings.

The release also fixes the complete browser suite's unknown-vendor scenario:
a display can remain a possible candidate while the vendor stays unassigned
and the item requires operator review. The v0.3.4 candidate passed 269 browser
checks but was not published because its older assertion rejected this safe
result on desktop and mobile Chrome.

No database migration or automatic customer-record reprocessing is required.
Automated recognition tests use fixtures and mocks, without paid recognition
requests. The corresponding Lens API and Scrapling worker release is v1.0.1.
