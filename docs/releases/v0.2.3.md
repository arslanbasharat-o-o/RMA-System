# RMA System 0.2.3

This security update makes login throttling use the client address supplied by the trusted reverse proxy. It also removes expired entries and limits how many addresses the app keeps in memory.

## Get the images

```bash
docker pull ghcr.io/arslanbasharat-o-o/rma-system:0.2.3
docker pull ghcr.io/arslanbasharat-o-o/rma-system:worker-0.2.3
```

The [container package page](https://github.com/arslanbasharat-o-o/RMA-System/pkgs/container/rma-system) lists the web and worker images. This release uses the MIT license. Existing deployments should follow the [deployment guide](https://github.com/arslanbasharat-o-o/RMA-System/blob/main/DEPLOYMENT.md) to back up data and update safely.

## Verification

The release workflow runs project checks, builds both container images, and runs the desktop and mobile browser suite with recognition providers mocked. The release and images publish only after validation passes.
