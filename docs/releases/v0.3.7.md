# RMA System 0.3.7

This release separates reviewer-confirmed models from automated suggestions. Dashboard model totals now count only reviewed records, RMA screens label suggestions and unidentified results clearly, and the review drawer no longer presents a heuristic evidence score as a match percentage. When the system keeps a safe same-image result after a Lens timeout or challenge, the provider failure remains visible.

## Verification

- All 134 unit and integration tests, typecheck, lint, and optimized production build passed locally.
- Desktop Chrome and Pixel 7 checks cover RMA result labels, camera intake, and dashboard layout at 320, 768, 1024, and 1440 pixels.
- Recognition tests use offline mocks and synthetic images; no paid recognition API was called during local validation.
- Full release CI remains the publication gate.
