# Release v0.4.9 — Seeded Display Inventory Catalog Integration

**Release Date:** 2026-10-29

## Overview
Release v0.4.9 introduces catalog-first display recognition using verified seeded display inventory references, automatic linking of box UPC/EAN barcodes and supplier SKUs, and removes obsolete legacy Excel catalog parsing.

## Highlights
- **Catalog-First Identification**: Uploaded display-back photos are evaluated against active seeded inventory references before calling Google Lens. Confident matches bypass Google Lens, reducing latency and external provider costs.
- **Automated Box Metadata**: Matches attach verified box UPC/EAN barcode values, formats, symbologies, and supplier SKUs directly to the RMA item.
- **Fallback Resilience**: Displays not matching seeded inventory fall back cleanly to the existing Google Lens and OCR pipeline.
- **Contradiction Safeguards**: Extracted physical part numbers that contradict a seed match withhold the seeded UPC/SKU and flag the item for human review.
- **Pipeline-Wide Link Validation**: OCR retries and manual model overrides validate and clear conflicting seeded links, confidence scores, and evidence atomically.
- **Intake Flow Alignment**: Mobile camera scanner defaults to the display back view.
- **Seed Management**: Added `npm run db:seed-display-inventory` with validation, dry runs, transactional application, and sample deactivations.
- **Cleanup**: Removed obsolete Excel catalog parsing code, tests, and dependencies.
