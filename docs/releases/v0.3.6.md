# RMA System 0.3.6

This release closes a legacy-evidence gap in repeat image identification. Older visual recognition runs that predate checksum tracking are matched using the selected image filename and upload time. If identical image bytes have conflicting stored model decisions, RMA keeps the item unidentified and routes it to operator review instead of choosing one result silently.

## Verification

- Regression coverage reproduces two conflicting legacy Lens decisions for the same image and confirms the new item remains review-required.
- All 133 unit and integration tests, typecheck, lint, optimized build, and mobile 36-step workflow passed locally. Full release CI is required before publication.
- No paid recognition API requests are part of the test.
