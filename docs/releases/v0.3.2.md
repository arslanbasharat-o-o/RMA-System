# RMA System v0.3.2

This release combines the visible Google Lens AI Overview with independently
attributed product listings. The overview is supporting evidence only: it
cannot identify a display on its own, and conflicting or ambiguous model names
stay in manual review. RMA now scores up to 30 listings.

Low-confidence visual guesses no longer surface as a specific model or
catalog-backed assembly. A matching physical part number can still identify a
catalog item, with visual disagreement recorded for review.

The interface uses consistent, accessible loading and status messages across
the dashboard, intake, review queue, and catalog screens. The camera and
inspection drawer were checked in desktop and mobile browser profiles.

This release requires no database migration. Completed recognition records are
not automatically reprocessed. The RMA and Lens test suites use offline
fixtures and mocks; no paid recognition request is part of release validation.
