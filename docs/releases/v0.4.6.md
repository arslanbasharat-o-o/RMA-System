# v0.4.6: AI Vision Gate for Ambiguous Models & Display Catalog Cleanup

## What changed

- **AI Vision Gate Fix**: Enabled OpenAI Vision (GPT-4o) inspection whenever Google Lens web candidates are ambiguous, conflicting, or low-confidence (< 0.85). Inspects the physical photograph alongside OCR markings to distinguish sibling device models (such as iPhone 16 Pro vs 15 Pro) by screen bezels, Dynamic Island dimensions, and flex cable markings. Updates `suggestedModel` and `displayName` while preserving human operator confirmation rules when source listings disagree.
- **Display Catalog Dead Code Removal**: Removed obsolete `/display-catalog` UI pages, layouts, and `/api/display-catalog` route handlers. The system dynamically matches models using Lens visual recognition and supplier/vendor rules. Vendor and supplier management (`/vendor-catalog`, `vendors`, `vendor_variants`, `vendor_recognition_rules`) remains active and intact.
