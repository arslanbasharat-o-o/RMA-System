# RMA System v0.3.21

- Shortlist Apple display candidates by counting unique, attributable publishers and weighting support by search rank. A clear vote maps to one catalog ID; duplicate sellers, accessory listings, mixed-model listings, and weak margins cannot create a single winner.
- Keep a bounded alternative set only when the vote is inconclusive and the verified-reference comparison can evaluate it. If there is no safe comparison set, abstain.
