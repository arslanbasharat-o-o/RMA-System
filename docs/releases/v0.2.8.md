# RMA System v0.2.8

This release adds the self-hosted Google Lens API and Scrapling Chrome worker
to the RMA source repository. It includes versioned container images for the
web app, RMA worker, Lens API, and Lens worker.

The RMA settings page reports self-hosted API and worker health without
displaying the API key. Production Compose keeps Lens services private, limits
the diagnostic port to loopback, and preserves the existing RMA database and
image volumes.

The worker now sends extensionless RMA image-store files to Chrome with a
filename and MIME type detected from their bytes. Model suggestions from
compatibility listings or insufficient/conflicting evidence stay in the review
queue instead of being marked as confident matches.

Validation included local RMA typecheck, lint, and unit tests; Lens API
typecheck, build, audit, API tests, Scrapling worker tests, and Redis recovery
integration; and a 15-run real-image RMA-provider sample over 13
production-stored image files. The sample completed without request failures;
the slowest non-cache run was 3.541 seconds. Uncertain model results remain
subject to staff review.
