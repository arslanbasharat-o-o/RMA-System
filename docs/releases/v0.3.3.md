# RMA System v0.3.3 (unpublished candidate)

The tagged release failed full mobile workflow validation and was not published.
Version v0.3.4 supersedes this candidate.

This release combines the reviewed intake and dashboard loading refinements with
more conservative Google Lens display identification. The visible AI Overview
is supporting evidence only; up to 30 independently attributed listings remain
the primary evidence, and conflicting or ambiguous model names stay in review.

Low-confidence visual guesses do not become specific model or catalog-backed
identities. Exact physical part-number matches remain available with visual
disagreement recorded for review.

Loading feedback uses accessible text and status semantics across desktop and
mobile. Browser regression checks now assert those user-visible states and the
busy state on asynchronous buttons. The earlier v0.3.2 candidate tag was not
published; this release supersedes it.

This release requires no database migration and does not reprocess existing
recognition records. Automated Lens tests use fixtures or mocks; release checks
do not issue paid recognition requests.
