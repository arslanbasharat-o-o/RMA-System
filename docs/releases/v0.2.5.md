# RMA System 0.2.5

This release keeps recognition results current while an inspection is open on a phone. The drawer refreshes during processing and when the browser resumes or reconnects, without erasing corrections that an operator is typing. Interrupted reads show a retry message instead of leaving an old processing state indefinitely.

Automated retries retain an operator's explicit model correction, and the inspection labels it as operator corrected. New recognition evidence remains visible for review.

Visual evidence now preserves each original source title and rank. iPhone Pro and Pro Max remain distinct, abbreviated model listings are recognized, and conflicting search results stay low-confidence suggestions for review. Catalog lookup no longer promotes uncertain recognition to a 95% match or arbitrarily chooses a SKU when several assemblies share a device model.

```bash
docker pull ghcr.io/arslanbasharat-o-o/rma-system:0.2.5
docker pull ghcr.io/arslanbasharat-o-o/rma-system:worker-0.2.5
```

Both images are published in the [container package](https://github.com/arslanbasharat-o-o/RMA-System/pkgs/container/rma-system). Back up the database and private image volume, then update the application and worker using the [deployment guide](../../DEPLOYMENT.md). This release requires no database migration and does not automatically change existing recognition records.

Validation uses synthetic images and mocked recognition providers. It includes recognition and evidence regressions, the full desktop/mobile Chrome suite, and focused mobile Safari intake and live result checks. No paid recognition requests are part of testing.
