# v0.3.31: focused verified comparison

The final verified-photo comparison now receives the discovery winner plus at
most two search-ranked alternatives. It no longer receives every model from the
winning discovery batch.

This is a reliability fix for the live iPhone 11 upload. On v0.3.30 the
discovery batch selected iPhone 11 at 0.88, but the final comparison received 32
reference items across eight models. The model returned `none` with confidence
0, claiming the references routed their flex on the opposite side. The reference
photos plainly show the same left-side routing as the upload.

A read-only production probe narrowed the final comparison to iPhone 11, iPhone
XR, and iPhone 16 Pro Max. The comparator selected iPhone 11 in three
consecutive attempts at 0.94, 0.94 and 0.93, citing both independent iPhone 11
references. Two attempts reported no unresolved alternatives; one retained a
note about the obscured connector contacts.

The winner keeps both independent examples. Only the closest competing labels
enter the final prompt, which preserves lookalike protection while avoiding a
prompt full of near-identical photos. The two-reference acceptance rule and the
0.93 score threshold from v0.3.30 are unchanged. Human review still applies to
results below the threshold, construction conflicts, and unresolved competing
models.

This release is built and deployed directly to production outside GitHub CI/CD
at the user's request. The temporary smoke-test records are removed after the
live replay.
