# RMA System v0.3.11

## Highlights

- **Display Catalog Loading & Pagination**: Resolved the infinite loading spinner on `/display-catalog` by correcting abort signal lifecycle handling, and added fast paginated querying (`limit`, `page`, `offset`, `compact`) and search filtering across 2,400+ display models.
- **Catalog SKU Matching in Synthesizer**: Improved multi-variant catalog resolution so that models manufactured in multiple technologies (e.g. Soft OLED, Hard OLED, COF) are accurately disambiguated against visual candidates to populate `internalSku` and `catalogDisplayId`.
- **UI Deduplication & Polish**: Cleaned up duplicated spinner states in the inspection drawer, unified status badge labels across RMA view, and surfaced recognized internal SKU badges with copy helper.
