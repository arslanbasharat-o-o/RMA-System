# RMA System 0.2.0

RMA System 0.2.0 brings the mobile display-intake flow, customer checks, dashboard refinements, and release-ready application and worker images together in one versioned release.

## Highlights

- Capture several inspection views for each returned display with a phone camera or image upload.
- Require customer information before an intake can start processing images.
- Review model and vendor identification results in the staff workflow.
- Find the application version and source revision in the published container metadata.

## Container images

The web application and background worker are published separately. Pull either image with Docker:

```bash
docker pull ghcr.io/arslanbasharat-o-o/rma-system:0.2.0
docker pull ghcr.io/arslanbasharat-o-o/rma-system:worker-0.2.0
```

The corresponding moving tags are `latest` and `worker-latest`. The [container package page](https://github.com/arslanbasharat-o-o/RMA-System/pkgs/container/rma-system) lists all tags and image details.

## Verification

The release passed TypeScript checks, lint, 92 unit and integration tests, a production build, Docker builds for both images, and 244 desktop and mobile browser tests. Recognition providers were mocked during CI.

## Deployment

The release contains deployable images; publishing it does not change an existing server. Follow the [deployment guide](https://github.com/arslanbasharat-o-o/RMA-System/blob/main/DEPLOYMENT.md) to update a Compose installation while preserving its database and storage volumes.
