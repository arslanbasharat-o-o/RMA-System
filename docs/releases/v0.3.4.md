# RMA System v0.3.4

This release stabilizes display identification when the exact same photo is used
again. The RMA worker records the image checksum and the visual decision policy
with each run. Later items with identical image bytes reuse an operator-confirmed
model or a corroborated visual result. Weak later searches cannot replace a
supported result; conflicting credible model variants are sent for review.

Google's visible AI Overview remains optional supporting evidence. Up to 30
independently attributable Lens listings provide the primary model evidence.
An explicit reprocess can collect fresh evidence while preserving the history
and highlighting a model conflict for staff review.

The mobile end-to-end workflow now selects the named navigation drawer when
returning to the Dashboard. Local validation passed 130 unit and integration
tests, TypeScript, lint, a production build, and the full 36-step mobile Chrome
workflow against an isolated database. Release publication requires the full
GitHub browser suite to pass. Automated recognition checks use mocks and
fixtures, without paid recognition requests.

This release requires no database migration. It does not rewrite existing RMA
records or reprocess customer images automatically. The v0.3.2 and v0.3.3
candidate tags were not published and are superseded by this version.
