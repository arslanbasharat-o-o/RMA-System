# Release v0.4.11 — Display Catalog Management, Matching Precision & Safety Hardening

**Release Date:** 2026-10-30

## Overview
Release v0.4.11 introduces a complete Seeded Display Inventory Management interface (`/display-catalog`), resolves a critical visual comparison bug that previously caused false ambiguity rejections on seeded display back photos, hardens test cleanup operations against accidental production record deletion, and eliminates all Next.js Turbopack build warnings.

## Highlights
- **Display Inventory Management Interface (`/display-catalog`)**:
  - Full-featured administrative page under the main navigation displaying all seeded products and references.
  - Interactive modal for inspecting high-resolution reference photos, crop coordinates, and physical markings.
  - Active and Matchable toggles with instantaneous optimistic UI updates and role-protected backend endpoints.
  - Dry-run sync preview diff against the seed manifest with one-click transactional synchronization.
  - Safe Test Data cleanup tool with candidate scanning and double confirmation safeguards.
- **Seeded Inventory Matching Precision Fix**:
  - Filtered conflicting cues so observations describing why unselected alternative references did not match do not block acceptance of the selected reference.
  - Clarified AI vision comparison system prompt to keep `conflicting_cues` strictly empty (`[]`) when the selected candidate matches without contradiction.
  - Resolves false ambiguity downgrade on RMA items (e.g. RMA `94bfc7fc-7137-4196-8dff-39d661736ac3` / item `2a4cee2f-5553-475a-84f9-a8a96bdf6b07`).
- **Zero-Downtime Deployment & Build Hardening**:
  - Eliminated dynamic filesystem tracing warnings during Turbopack compilation.
  - Verified 30 test suites (234 tests) passing with 100% success rate.
  - Full typechecking and linting verification.
