# RMA System 0.2.1

This patch makes the public release and container pages easier to understand and use.

## Package details

- The web and worker images now publish distinct descriptions, the MIT license, the repository link, version, and source revision as OCI metadata.
- The README lists the exact application and worker image tags and copy-ready Docker pull commands.
- The release page includes project highlights, verification results, and deployment guidance.

## Verification

This release passed the repository's full release workflow, including the desktop and mobile browser suites and production builds of both container images. Recognition providers were mocked during CI.

## Container images

```bash
docker pull ghcr.io/arslanbasharat-o-o/rma-system:0.2.1
docker pull ghcr.io/arslanbasharat-o-o/rma-system:worker-0.2.1
```

The [container package page](https://github.com/arslanbasharat-o-o/RMA-System/pkgs/container/rma-system) shows the current descriptions and all published tags.
