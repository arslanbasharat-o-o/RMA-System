# RMA System v0.3.20

- Use operator-verified displays as bounded runtime examples for uncertain model recognition. Part numbers need two independent verified items with the same catalog model; conflicting mappings are withheld for human review.
- Compare front-notch crops only with front-view references and flex/connector crops only with back or flex references. Intake now supports a separate flex-cable close-up.
- Keep verified labels under human control. Feedback augments retrieval and catalog matching at inference time; it does not fine-tune model weights or guarantee a fixed accuracy.
- Preserve all database and image-storage volumes. This release uses the existing schema and does not require a migration.
