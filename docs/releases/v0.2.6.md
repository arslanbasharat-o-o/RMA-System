# RMA System v0.2.6

This release refreshes the operations interface and makes recognition failures easier to recover from on phones and desktops.

## Updated interface

- Consistent responsive layouts across the dashboard, intake, inspection, catalogs, reports, login, and settings.
- Searchable selection controls, accessible keyboard navigation, action menus, and a sidebar that remembers its collapsed state.
- Dashboard trends reflect saved activity; unavailable trends stay hidden.
- Processing updates and operator corrections remain visible in the inspection drawer.

## Recognition recovery

- Visual search has a bounded, configurable timeout (`LENS_TIMEOUT_MS`, default 60000) to tolerate provider slowdowns.
- Text recognition runs independently of visual search, so a slow visual provider does not block the text stage.
- Saved partial results, clear failure details, and explicit retry actions help staff continue reviewing a display.
- Failed retry submissions keep the inspection drawer open.

Google Lens recognition still depends on SerpApi availability. These changes improve recovery and preserve partial results; they do not remove that external dependency.

## Verification

Application source passed 112 unit and integration tests and 283 browser checks across desktop Chrome, mobile Chrome, and mobile Safari before release preparation. Release CI repeats production builds and the full browser suite with synthetic media and offline recognition mocks. No paid recognition request is used for release validation.
